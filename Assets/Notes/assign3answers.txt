Exercise 15)  Prefab asset is like a template we plan on using over and over in real time. 
We use isntantiate to create a new copy of the prefab and that costs us memory for every one we create.
This is where we do pooling and reuse an existing pooled object and we turn it on or off so we can do that.
Dynamically growing a pool creates new objects only when the original pool runs out which can cause a performance
spike in that moment, and instantiating every time repeatedly just pays the cost of memory during gameplay.
